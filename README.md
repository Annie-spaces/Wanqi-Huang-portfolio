# Wanqi Huang — Portfolio

A static personal portfolio with separate About Me, Resume, Projects, and Personal Interests pages.

## Publish with GitHub Pages

In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.

The site will be available at https://annie-spaces.github.io/Wanqi-Huang-portfolio/.

## Editing

Page content is in app.js. Styling is in styles.css. Replace wanqi-huang-resume.pdf to update the downloadable resume. Portrait and personal interest images are placeholders.

Open index.html locally to preview. No build step is required.
